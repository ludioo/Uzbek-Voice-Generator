# Contributing

Thank you for your interest in contributing to Uzbek Voice Generator.

## Ways to Contribute

You can contribute by:

- Reporting bugs
- Suggesting features
- Improving documentation
- Improving translations or Uzbek language handling
- Testing the application
- Submitting pull requests

## Reporting Bugs

Before opening a bug report:

1. Check whether the issue already exists.
2. Use the latest release if possible.
3. Include the application version.
4. Describe the steps to reproduce the problem.
5. Include the expected behavior.
6. Include the actual behavior.
7. Include relevant error messages.

Do not include unnecessary personal information.

## Feature Requests

Explain:

- What problem the feature solves
- Why it would be useful
- How you expect it to work

## Pull Requests

Before submitting a pull request:

1. Keep the change focused.
2. Avoid unrelated refactoring.
3. Update documentation when necessary.
4. Run the existing tests (`pytest`).
5. Explain what changed and why.

Voice availability depends on Microsoft Edge TTS through the `edge-tts` package. Requests for new voices are welcome as feedback, but additions are not guaranteed by this project.
